## About This Project

A comprehensive boat rental marketplace frontend built with Next.js and Material UI. This project demonstrates advanced frontend architecture patterns and complex state management.

### Key Features

- **Search & Discovery**: Advanced filtering and search for boat listings
- **Booking System**: Complete reservation flow with date selection
- **User Dashboard**: Profile management and booking history
- **Responsive Design**: Mobile-first approach with Material UI
- **API Integration**: Seamless connection with Flask backend

### Technical Highlights

- Server-side rendering for SEO optimization
- Custom hooks for state management
- Reusable component library
- Form validation with error handling
- Image optimization and lazy loading
